# Security Policy

## Supported Versions

Only the latest release receives security fixes.

| Version | Supported |
| ------- | --------- |
| latest  | ✅        |
| older   | ❌        |

## Reporting a Vulnerability

Please **do not** open a public issue for security problems.

Report privately via GitHub's
[Private vulnerability reporting](https://github.com/tntrock/endpoint-manager/security/advisories/new).
Include affected version, reproduction steps, and impact if known.

You can expect an initial response within 7 days. Once a fix is released,
the advisory will be published with credit to the reporter (unless you prefer otherwise).
