# 表格排序、篩選與批次操作（UI 改版第四期）

日期：2026-11-21
前身：`2026-10-03-ui-redesign-design.md` §1.1 第四期。

## 1. 範圍

**做：**
- 欄位排序：裝置清單、違規清單、派送詳細頁的裝置表。
- 篩選：派送清單依狀態；遠端指令清單依動作、只看有失敗的。
- 批次操作：
  - 裝置清單：勾選多台後移到群組、下遠端指令、除役。
  - 違規清單：勾選多筆後建立豁免。

**不做：**
- 跨頁全選（「選取所有符合條件的」）：一次最多一頁（50 筆）。
- 拖曳欄位、自訂欄位。
- 用 JavaScript 在瀏覽器端排序（排序一律由伺服器做，翻頁才正確）。

**限制：** 沿用前幾期（CSP、沒有 JS 也能用）。「全選」核取方塊需要 JS，沒有 JS 時逐一勾選。

## 2. 排序

- 網址參數 `sort=<欄位>`，遞減加 `-` 前綴（例：`sort=-last_seen`）。不認得的值用預設排序。
- 欄位名稱對應到伺服器端的白名單 SQL 運算式，參數本身不會進 SQL。
- 每個排序都附上原本的穩定次序（例如 id），翻頁結果不重複、不遺漏。
- 表頭變成連結：點一下遞增，再點一下遞減；目前排序的欄位標示 ▲／▼，並加上 `aria-sort`。
- 換排序時回到第 1 頁；篩選條件保留。

| 表格 | 可排序欄位 | 預設 |
|---|---|---|
| 裝置清單 | 電腦名稱、群組、作業系統、使用者、IP、最後報到、狀態 | 電腦名稱 |
| 違規清單 | 電腦名稱、群組、規則、嚴重度、狀態、開始時間 | 開始時間（新到舊） |
| 派送詳細頁的裝置 | 電腦名稱、狀態、更新時間 | 電腦名稱 |

## 3. 篩選

- 派送清單：全部／進行中（試點、全部派送）／已暫停／已停止，以標籤連結切換，附各自數量。
- 遠端指令清單：動作下拉選單；「只看有失敗的」勾選。

## 4. 批次操作

### 4.1 裝置清單

- 每列前面加核取方塊，表格上方是批次操作列：選擇動作、必要的參數、送出。
- 檢視者看不到核取方塊與操作列。
- 動作與權限：

| 動作 | 誰能用 | 說明 |
|---|---|---|
| 移到群組 | 平台管理員 | 與單台相同，逐台寫稽核記錄 |
| 遠端指令 | 群組管理員以上（腳本限平台管理員） | 建立一筆指令，對象是勾選的裝置，標籤為「N 台裝置」 |
| 除役 | 群組管理員以上 | 需要勾選確認，逐台寫稽核記錄 |

- 範圍外、不存在或不是使用中的裝置一律略過。結果訊息列出成功台數與略過台數；略過的不顯示細節（群組管理員無法藉此探測範圍外的裝置）。
- 遠端指令：作業系統不符的裝置與群組指令一樣略過並記在 `skipped_os`；全部都不符時回錯誤。
- 一次最多 200 台（目前每頁 50 台，留有餘裕）。

### 4.2 違規清單

- 平台管理員才有核取方塊（豁免本來就只限平台管理員）。
- 操作列：原因、有效天數，送出後對每個勾選的（裝置, 規則）建立或更新豁免。值是 `<裝置 ID>:<規則 ID>`。
- 已是豁免狀態的也可以選，效果是更新原因與到期日。
- 結果訊息顯示建立的筆數；格式錯誤或已不存在的略過並計數。

## 5. 測試

- 排序：每個表格至少一個遞增與遞減的情況；不認得的欄位用預設；表頭連結保留篩選條件、標示目前方向。
- 篩選：派送依狀態、指令依動作與失敗。
- 批次：
  - 移群組、除役、指令的成功與略過計數。
  - 範圍外裝置不受影響。
  - 檢視者 403。
  - 群組管理員不能批次移群組、不能批次執行腳本。
  - 豁免批次建立，非平台管理員 403。
- CSRF 檢查。
