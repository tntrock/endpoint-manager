# 總覽儀表板改版與主管報告（UI 改版第二期）

日期：2026-11-21
前身：`2026-10-03-ui-redesign-design.md` §1.1 第二期；視覺依據 `2026-10-03-ui-redesign/dashboard-mockup.html`。

## 1. 範圍

**做：**
- 每日裝置統計表，供趨勢圖使用。
- 總覽頁改版：四張指標卡（含迷你趨勢）、違規趨勢圖、需要處理清單、各據點狀態、違規最多的規則。
- 可列印的主管報告 `/report`（瀏覽器列印或存成 PDF）。
- 裝置清單新增「長期離線」篩選（需要處理清單的連結目標）。

**不做：**
- 伺服器端產生 PDF（不加依賴；瀏覽器「存成 PDF」即可）。
- 排程寄送報告。
- 自訂儀表板版面。

**限制（沿用第一期）：** CSP `default-src 'self'`，不能有 inline style 屬性或 inline script；圖表一律由伺服器產生 SVG，顏色用 class 搭配 CSS 變數，深淺色主題都適用。沒有 JavaScript 時功能完整。

**權限：** 所有角色都能看總覽與報告，數字一律限於自己的管理範圍（平台管理員看全部，其他角色看自己的群組）。

## 2. 每日統計

新資料表 `device_daily`：

| 欄位 | 說明 |
|---|---|
| `day` | 管理網頁時區的日期（與 `compliance_daily` 一致） |
| `group_id` | 群組；0 代表未分組。不設外鍵：群組刪除後，平台管理員的加總仍保留歷史 |
| `managed` | 受管裝置數（不含已除役、待核准） |
| `seen` | 其中 24 小時內有回報的台數 |
| `compliant` | 其中沒有任何違規的台數 |
| `high_risk` | 其中有高風險違規的台數 |

- 主鍵 `(day, group_id)`。
- 合規背景工作每小時寫入（upsert）「今天」的數字（與 `compliance_daily` 同時），伺服器啟動時先寫一次。升級當天就有第一個點；一天內最後一次寫入就是當天的值。
- 多台伺服器同時寫入沒有問題（同一天覆寫）。
- 保留天數沿用 `violation_history_days`（與 `compliance_daily` 一起清理）。
- 範圍內的趨勢＝把可見群組的列加總。

## 3. 總覽頁

頁首：標題、範圍說明（「全部裝置」或群組名稱）、按鈕「主管報告」。期間切換 `?days=7|30|90`（預設 30；其他值當 30），用連結實作。

### 3.1 指標卡

| 卡片 | 數值（即時） | 輔助 |
|---|---|---|
| 裝置總數 | 受管裝置數 | 較 7 天前增減；期間內的迷你折線 |
| 在線 | 在線／總數 | 環形百分比 |
| 合規率 | 沒有違規的台數／總數 | 較 7 天前增減（百分點）；迷你折線 |
| 高風險裝置 | 有高風險違規的台數 | 迷你折線 |

7 天前沒有資料時不顯示增減。

### 3.2 違規趨勢

- 期間內每天的「有違規」與「高風險」台數兩條線，Y 軸 4 格、X 軸最多 5 個日期標籤。
- 沒有資料的日子不補值（折線直接連到下一個有資料的日子）。
- 少於 2 個點時顯示「累積兩天以上的資料後會顯示趨勢」。

### 3.3 需要處理

依嚴重度排序，每項是一個連結並附台數；沒有項目時顯示「目前沒有需要處理的項目」。

| 嚴重度 | 項目 | 連結 |
|---|---|---|
| 高 | 每條有違規的高風險規則（最多 3 條，台數多的優先） | 該規則的違規清單 |
| 高 | 每個有失敗的進行中派送（最多 3 個） | 派送詳細頁 |
| 中 | 等待重新開機超過 7 天 | Windows Update 概況 |
| 中 | 離線超過 7 天 | 裝置清單「長期離線」 |
| 中 | 疑似重複 | 裝置清單「疑似重複」 |
| 低 | 待核准的重新註冊 | 本頁下方的核准區 |

「進行中」＝stage 不是 `stopped`。

### 3.4 各據點狀態

- 只在有設定據點時顯示。
- 裝置依最後回報的 IP 對應據點；符合多個據點時取網段最精確的。沒有對應的歸在「其他」。
- 每個據點一條堆疊長條：在線且合規、在線但有違規、離線，加總台數。

### 3.5 違規最多的規則

範圍內違規台數最多的 5 條規則（台數 > 0），長條長度相對第一名，顏色依嚴重度，連到規則的違規清單。

### 3.6 待核准的重新註冊

維持現有區塊與行為。

## 4. 主管報告 `/report`

- 獨立頁面（不含側邊欄與頂端列），A4 直式列印友善，固定使用淺色配色。
- 期間 `?days=7|30|90`，預設 30。
- 內容：
  1. 標題、範圍、期間、產生時間與產生者。
  2. 指標：裝置總數、在線率、合規率、高風險裝置，各附較期初的變化。
  3. 違規趨勢圖（同總覽）。
  4. 依嚴重度的違規：各嚴重度的規則數與違規台數。
  5. 違規最多的 10 條規則。
  6. 各據點狀態表（有據點時）。
  7. Windows Update：等待重新開機的台數（及超過 7 天的台數）、更新原則狀態分布。
  8. 進行中的派送：名稱、階段、成功、失敗。
- 「列印／存成 PDF」按鈕由 JS 顯示並呼叫 `print()`；沒有 JS 時提示用瀏覽器的列印功能。

## 5. 裝置清單「長期離線」

狀態篩選新增 `stale`：受管裝置中最後回報早於 7 天前，或從未回報。

## 6. 測試

- 統計：寫入當天快照後，各欄數字正確；重複寫入覆寫；群組範圍加總正確。
- 圖表產生函式（純函式）：座標換算、空資料、單點、日期標籤數量。
- 總覽：群組管理員只看到自己群組的數字與需要處理項目；需要處理清單包含高風險規則、派送失敗、長期離線；期間參數。
- 據點：IP 對應到最精確的據點，沒有對應的歸在「其他」。
- 報告：各角色都能開，範圍正確，HTML 不含 inline style。
- 裝置清單 `status=stale`。
